Near-black, high-contrast, developer-tool energy. One electric accent color does all the work.

Palette: bg #0a0a0f, surface #14141c, text #f2f2f5, muted #8a8a96, accent #5eead4 (teal, or swap to #a78bfa violet), border #24242e
Type: sans-serif (Inter/system-ui) for body, monospace (JetBrains Mono/ui-monospace) for headings/labels/code. Weights 500/700. Display 48px/700/-1px, body 16px/500/1.6.
Spacing/radius: 4/8/16/32/64px scale; radius 6/10/16px, sharper 2-4px on code blocks
Shadow: glow, not drop-shadow - accent-tinted, e.g. 0 0 24px rgba(94,234,212,0.15) on hover/active states only

Do: monospace for stats/labels/badges; thin 1px borders over shadows for separation; a subtle grid/dot background texture
Don't: use pastel or warm tones; use pure black (#000); overuse the glow effect outside interactive elements; add drop shadows on cards
