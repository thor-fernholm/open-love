Bold and energetic - a signature gradient, rounded cards, confident color. Feels like a modern product-launch page.

Palette: bg #ffffff, surface #f8f7ff, text #1a1a2e, muted #6b6b80, gradient accent1 #7c3aed to accent2 #ec4899 (purple-to-pink), border #ece9f7
Type: sans-serif (Inter/system-ui), weights 500/700/800 (this system allows extra-bold for hero headlines). Display 56px/800/-1.5px, body 17px/500/1.6.
Spacing/radius: 8/16/24/48/80px scale; radius 16/24px on cards, 9999px on the primary CTA only
Shadow: colorful glow under primary CTAs (0 12px 24px rgba(124,58,237,0.25)); soft neutral shadow on cards (0 4px 16px rgba(26,26,46,0.06))

Do: use the gradient as a background wash behind the hero or on the primary CTA, not on every element; bold large headline type; rounded card grids for features
Don't: apply the gradient to body text or small UI elements; use more than one gradient pairing per page; use muted/desaturated colors elsewhere
